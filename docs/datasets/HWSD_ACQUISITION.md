# HWSD native acquisition

ZEUS acquires FAO's exact HWSD v2 mapping-unit raster and original Access database. The grid contains identifiers, not interpolated soil properties. Each export includes a native-grid GeoTIFF, AOI validity/extent masks, and a JSON table artifact containing every linked component and all seven depth intervals. Field metadata, classification dictionaries, component shares, original numeric precision, nulls and provider sentinel values remain available. There is no dominant-component selection, weighting or renormalization.

[FAO's product page](https://www.fao.org/land-water/resources/tools/databases/hwsd/en) documents the v2/v2.01 release history and the linked files. The two archives are frozen independently: the linked MDB has a January 2023 HTTP modification date and the raster September 2023. Neither date establishes the age of local observations. Dates, accuracy and unresolved source-licence details are visible during review. A source change requires renewed qualification; execution never substitutes another release or a converted database.

The original MDB's 25 user tables were compared in full against an independent Microsoft Access ODBC read. The pinned pure-Python reader reproduces all native table row multisets, including 408,835 layer records. That ODBC installation is an independent verification instrument, not a replay dependency. The ISRIC SQLite copy was investigated and rejected for exact-value use: 92,568 layer records still differed after restoring the original floating-point field precision. [Verification evidence](../../qa/hwsd-native-verification.json) preserves both results, source hashes and the comparison method.

Each execution verifies the original archive hashes, archive CRCs, required members, native grid, table inventories and complete row hashes. Database rows are decoded one page at a time. The 1,866,240,000-byte BIL is streamed inside its retained ZIP; only the 91,594,752-byte MDB is expanded to temporary disk. Raster coordinates and values remain native; canonical WGS 84 axis metadata is assigned only after checking the source PRJ. Original declarations and the normalization operation remain in provenance.

Every grid identifier must link to one mapping-unit record and complete component/depth records. Missing IDs, duplicated depths, changed native values or inconsistent component identities block publication. Component shares that do not total 100 are reported without changing the values. Coverage of mapping units is separate from availability of individual properties. The table export reports null and minus-nine counts; it does not infer property values or local scientific suitability.

The dataset index includes the table artifact and its validated download link. Map previews apply the AOI mask on the display grid after reprojection, so AOIs smaller than a native cell remain visible without changing the analytical grid. The portable provenance bundle retains both entire original archives, the frozen plan, exact implementation, runtime fingerprint and validation evidence. Product-wide qualification, broader AOIs and final licence assessment remain outstanding even after successful sample replays.

The native-table verification contract is generated by ZEUS and retained with a `zeus:qualification/` identity. The FAO documentation URL is a reference within that evidence, not an assertion that FAO returned the locally generated JSON. Earlier QA bundles remain unchanged and their versioned implementation remains visible.
