# Scientific acquisition implementation status

Updated 2026-09-17. **The requested programme is not complete and ZEUS is not yet fully qualified for scientific research.** The local implementation and its evidence are available for review. Nothing has been deployed publicly or pushed to GitHub during this work.

## Implemented locally

- Versioned products, selections, frozen plans, receipts, findings and manifests. Backend confirmation binds exact plan hash, acknowledgement IDs, AOI, explicit reference time, policy, parameters and runtime. Catalogue aliases cannot silently select a different product or release.
- Durable background discovery with saved selections, a fixed reference time, restart recovery, a 30-minute deadline, a 2 GiB retained-discovery budget and explicit cancellation before confirmation. Browser refresh/reopen reconnects to the same discovery.
- SQLite WAL job ledger, transactional state changes, per-object acquisition checkpoints, retained partial validation evidence, one active acquisition per project and supervised dedicated worker. Pending approvals survive restart.
- Verified input caches bind strong provider object identities to content hashes; reuse requires fresh source-identity checks and retained-byte verification. SHA-256 content-addressed raw inputs, discovery and retained documentation responses; deterministic ordering; bounded downloads, retries, deadlines, storage and cell limits. HTTP subprocesses stop on cancellation or parent death.
- Full raster band scans with AOI holes, boundary-cell accounting, measured gaps and downloadable masks; strict CRS/units/calibration/class validation. Unmasked NaN/infinity blocks publication; declared NoData remains a measured gap. Categorical results include class counts and fractional AOI areas. Vector ID inventories, pagination, typed response checks, canonical ordering, clipping and feature-loss accounting. Verified empty vectors are distinct from incomplete extracts.
- Report-specific gap acceptance, hard blockers that cannot be waived, verified output integrity and immutable generations with an atomic visible-manifest switch. Inventory, map, downloads and cache readers resolve committed content.
- Offline replay and portable provenance ZIPs with retained implementation, runtime fingerprint, inputs, discovery, reports, event history, outputs and integrity inventory. Windows reference package builds and PROJ resources are locked; other platforms remain unqualified.
- Country-aware registry defaults avoid choosing national products for unrelated country hints; explicit out-of-coverage selections require acknowledgement. Review includes dated live/discovery outcomes and whether a sample used the current implementation, without promoting those checks to full qualification.
- Mandatory source review, individual provider acknowledgements, job history/reconnect, report review, gap downloads, export downloads and source metadata in the dataset index. Existing project workflow, Cesium viewer and separate AOI picker remain.
- Legacy artifacts remain readable and labelled unverified. A revalidation command preserves a present-artifact snapshot, scans its current properties, and explicitly leaves historical provenance and original-input replay unknown. Waterloo's existing DEM was revalidated without changing it or publishing a generation.
- Publication flushes output artifacts, uses same-filesystem atomic replacement with the platform durability request, and verifies the immutable generation manifest for readers. Earlier datasets retained in a new generation are rechecked, including masks, before commit. Hardware power-loss guarantees remain unqualified.
- Map previews bind the frozen AOI, scientific input, recipe and validity mask in their cache identity. AOI holes and invalid cells remain transparent; native analytical values are unchanged. Documentation-fetch storage failures and input-budget failures stop planning rather than becoming acknowledgeable provider outages.
- Plans freeze exact coordinate pipelines for analytical rasters, vector conversion, native-grid AOI subsets and validation, with their stated operation accuracy. Missing higher-accuracy transformation grids require an individual acknowledgement. Mixed-CRS assets are each resampled once onto the frozen grid and merged without another resampling; clipping follows interpolation to avoid artificial boundary gaps.

- Portable previews now resolve and verify the original plan retained in the generation before using a local ledger fallback. Shared input objects count once against the retained-byte budget; conflicting receipt lengths block execution. Publication resolves nested prior-generation mask paths correctly and still rejects actual corruption.
- Preview AOI clipping now masks display pixels after reprojection, preserving visible intersections when an AOI excludes every native cell centre. Holes and validated gaps remain transparent. The display cache uses the corrected renderer policy; scientific rasters are unchanged.

- USGS 1 m discovery now interprets equivalent CRS names, EPSG declarations and structured UTM parameters instead of requiring exact wording. Explicit supported NAD83 realizations are preserved, contradictions identify the affected tile, and metadata outside the AOI cannot block acquisition for unrelated CRS details. The retained metadata that triggered the reported error now resolves successfully; see [compatibility evidence](../../qa/usgs-crs-compatibility.json). This is not a new full live-acquisition qualification.

## Adapter coverage

There are **60 registered products** across the 14 categories. Shared clients cover HTTP/S3, STAC, ArcGIS, OGC Features, Overpass, CDS and provider-specific discovery. Registered products include Copernicus GLO-30/GLO-90, three USGS 3DEP resolutions, both WorldCover releases, eleven SoilGrids properties, GEM PGA, five OSM selections, Canadian CER/CPCAD/CLSS/NHN/HRDEM, SwissALTI3D, OS Open Roads/Rivers/Terrain 50, Sentinel-2 L2A, ERA5, WorldPop, seven WorldClim variables, HydroRIVERS, HydroLAKES, GHS-POP, JRC surface-water occurrence, FRA North American Rail Network lines/nodes, Census 2026 Indigenous legal/statistical area types, CGIAR-CSI SRTM 4.1, Norwegian established/proposed conservation areas, England national/local nature reserves, and three distinct Impact Observatory/Esri land-cover model releases.

All eleven SoilGrids properties retain encoded units and explicit depth/statistic choices. Publisher SHA-256 inventories verify the VRT and every selected tile. Native tile grids are reconciled with the index, including its unusually coarse source windows; processing bypasses VRT upsampling and applies one analytical resampling. Carbon stock uses its distinct 0–30 cm contract. Public coarse soil-water grids have been identified and their checksums and official documentation retained; their implementation remains outstanding. See [interface assessment](soilgrids-water-assessment.md).

Impact Observatory's original 2020 ten-class map, annual nine-class V1 and V2 are separate products with pinned legends, explicit year selection, complete discovery pagination and native UTM subsets. Previous-year items that only touch the search interval boundary are excluded. Cloud-class coverage remains a valid provider code and requires a separate suitability acknowledgement when present. OS Terrain 50 preserves the full nested national archive, tile dependencies, flying/processing/metadata dates, height reference and publisher MD5. Its ASCII/PRJ/GML contracts are reconciled before review; rounded PRJ scale normalization is recorded explicitly. Source styling statistics are not used as validation.

Imagery keeps individual selected scenes and bands, SAFE processing baseline and radiometric calibration, native grids and SCL quality layers. WorldPop and GHS retain native counts. WorldClim exports all twelve months as CF-described climatology and a separately identified January map preview. ERA5 freezes individual day/variable requests, checkpoints each complete response and its request/result metadata, and accepts only an unambiguous NetCDF member when the provider archives a response. Fixtures verify exact hourly time steps, calendar, units, accumulation semantics, native grid registration, per-hour AOI coverage, time bounds and value-preserving CF export. Instantaneous data receives no invented accumulation interval. Live ERA5 acquisition remains unverified without CDS credentials.

USGS 1 m uses the official project index, reconciled S3 listings and companion tile metadata. Source grids are checked against a frozen numerical tolerance, with actual affine coefficients retained. USGS 10 m and 30 m have an explicit published-tile interface with retained FGDC metadata; it is distinct from the TNM search interface and never substitutes another DEM. Publication-date ranges are not presented as observation dates. The December 2025 CPCAD file release is acquired through ECCC's official catalogue/file authorization interface; temporary authorization links are excluded from provenance. Current and delisted areas are separate selections, with linked provider comments preserved. OSM freezes root IDs/versions before recursively acquiring relation descendants; member paths, roles, tags and geometry dependencies are retained and checked. Cycles and unresolved members fail explicitly. ArcGIS clients validate declared attributes, coded domains and geometry types, and disclose provider coordinate conversion. NHN optional M values remain in original ISO WKB with their CRS; clipped XY/Z geometry is a derivative, and unknown M units require specific review. HRDEM accepts exact acquisition IDs without substitution; both Saskatoon DTM and DSM passed live checks.

FAO HWSD v2 now preserves the original mapping-unit raster and MDB, every linked component and depth, and metadata/domain tables. All 25 native user tables match an independent ODBC row comparison, including 408,835 layer records. The investigated ISRIC SQLite conversion failed exact native-value comparison and is not substituted. Native row decoding, grid IDs, depth bounds and shares are checked; canonical WGS 84 axis metadata is recorded without resampling. The raw table export is available through the project index, with correct table totals and filtering. Plan review distinguishes the project CRS from the native analytical CRS. ZEUS-generated qualification contracts use a local evidence identity instead of a provider-response URL. Source licence details and full product qualification remain unresolved. See [HWSD acquisition](HWSD_ACQUISITION.md) and [native comparison evidence](../../qa/hwsd-native-verification.json).

Registration and an acknowledgement disposition **do not mean full product qualification**. The product assessment exposes pending checks. Passing a small live AOI also does not establish complete country coverage, all parameter combinations or fitness for a particular analysis.

## Unfinished delivery gates

1. Complete every catalogue requirement against official documentation and actual service capabilities; implement and test all remaining eligible national/provider products. The 269 unavailable rows are not permission to abandon difficult adapters.
2. Qualify free-account services when credentials are available. All three registered USGS resolutions now have successful live checks through exact official published interfaces; the optional TNM search interface still returns an internal error.
3. Run live acquisition for every registered product and parameter contract, including larger HRDEM selections. OS Open Roads and SRTM 4.1 now have successful live acquisitions and two replays. All seven WorldClim variables and explicitly selected HRDEM DTM/DSM surveys have passed live checks. OSM powerlines passed a verified-empty sample. Railway/waterway/pipeline acquisition attempts encountered rate limits/timeouts; they remain unresolved. Complete ERA5 live qualification, including provider finality and independent export conformance.
4. Expand full geometry/domain qualification across national providers and nonempty vector AOIs. OSM relation members are exported with their hierarchy, without implicit polygon assembly.
5. Complete independent format-conformance checks and source-specific geometry qualification. Raster and vector processing, validation, native AOI subsets, and SoilGrids/NHN index operations now record their coordinate pipelines; normalization of project AOI files now preserves the original dependencies and exact coordinate operation, and offline replay reconstructs the same AOI. Source boundaries use transformed vertices without geodesic densification; broader source-geometry qualification remains pending. Polar-cap winding and unsupported native longitude wrapping currently fail explicitly; ordinary polar and antimeridian fixtures are covered.
6. Six real-process crash boundaries now pass publication recovery: before/after the generation rename, before/after the manifest switch and before/after the ledger commit. Post-switch errors reconcile as published rather than failed; pre-switch failures retain the old visible generation. Complete broader concurrent cancellation/fault combinations and platform/storage qualification. Independent recreation of the pinned reference environment has passed on this computer; other machines and platforms remain unqualified.
7. Complete browser acceptance coverage for all expanded categories, all export formats, and every remaining approval/recovery path. Keep live checks separate from immutable fixtures.

The source licence for the software extraction is still undecided. Provider licences and attribution are separate metadata; neither a passing acquisition nor an acknowledgement grants redistribution rights.
